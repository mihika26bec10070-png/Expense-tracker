Expense Tracker - Project Statement

1. Problem Statement

Managing daily expenses manually can be difficult. People may forget their expenses, lose records, or find it difficult to calculate how much money they have spent in different categories.

The Expense Tracker is a simple Python-based application that allows users to record, view, update, and delete their expenses. It also calculates the total expense and provides category-wise expense analysis.


2. Scope of the Project

The scope of this project is to provide a simple and easy-to-use expense management system for recording and analyzing daily expenses.

The project focuses on:

- Adding new expenses
- Viewing saved expenses
- Updating existing expenses
- Deleting expenses
- Calculating total expenses
- Performing category-wise expense analysis
- Storing expense records in a CSV file
- Validating user inputs

The project is designed as a beginner-level Python application and can be extended with additional features in the future.


3. Target Users

The intended users of this application are:

- Students
- Beginners learning Python
- Individuals who want to track daily expenses
- Users who want a simple personal expense management system


4. Features

The main features of the Expense Tracker are:

Add Expense
Users can enter:

- Amount
- Category
- Date
- Description

View Expenses
Users can view all the expenses stored in the system.

Update Expense
Users can modify the details of an existing expense.

Delete Expense
Users can remove an unwanted expense record.

Total Expense
The application calculates and displays the total amount spent.

Category Analysis
The application calculates the total amount spent in each category.

Data Storage
Expense records are stored in a CSV file so that they can be used again when the program is run.

Input Validation
The application checks whether the entered amount and text values are valid.

5. Technologies Used

- Python
- CSV file handling
- Python functions
- Dictionaries
- Lists
- Conditional statements
- Loops
- Basic exception handling
- GitHub for version control
