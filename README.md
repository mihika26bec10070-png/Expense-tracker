# Expense-tracker
A simple Python-based Expense Tracker to add, view, and calculate daily expenses. Perfect for beginners and 1st-year B.Tech students.
💰 Expense Tracker

A simple Expense Tracker made using Python.
This project is designed as a beginner-friendly mini project for 1st-year B.Tech students.

📌 Features

- ➕ Add an expense
- 📋 View all expenses
- 💵 Calculate total expenses
- ❌ Exit the program
- 🖥️ Simple menu-based interface

🛠️ Technologies Used

- Python 3
- Lists
- Functions
- Loops
- Conditional statements
- User input

🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

python expense_tracker.py
