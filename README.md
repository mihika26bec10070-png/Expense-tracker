# Expense-tracker
A simple Python-based Expense Tracker to add, view, and calculate daily expenses.

Expense Tracker

A simple Expense Tracker made using Python.

Features

-  Add an expense
-  View all expenses
-  Calculate total expenses
-  Exit the program
-  Simple menu-based interface

Technologies Used

- Python 3
- Lists
- Functions
- Loops
- Conditional statements
- User input

python expense_tracker.py

Purpose

The purpose of this project is to practice basic Python programming concepts such as:

- Variables
- Lists
- Functions
- "if-else" statements
- "for" and "while" loops
- User input

Future Improvements
